Name of project : Dev-Stract-app.
description :
A React-based application that allows users to browse technologies and build their own developer stack by adding and removing technologies dynamically.
Technology :
 ⚛️ React.js — Build the user interface
📘 TypeScript — Type-safe JavaScript
🎨 Tailwind CSS — Styling and responsive design
🌼 DaisyUI — Ready-made UI components
🔄 React Hooks — State and component management
🌐 Fetch API — Fetch technology data
📦 JSON — Store and manage technology data
⚡ Vite — Project setup and development server
🧭 React Suspense — Handle asynchronous data loading
